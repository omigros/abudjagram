# Abudjagram

Десктопный форк [Telegram Web A](https://github.com/Ajaxy/telegram-tt) на Electron с расширенной кастомизацией внешнего вида.
Лицензия — GPL-3.0, как у оригинала: при распространении сборок исходный код форка должен быть открыт.

## Первый запуск

1. `npm install`
2. Получите `api_id` и `api_hash` на [my.telegram.org](https://my.telegram.org) → API development tools.
3. Введите их на экране «Ключи Telegram API», который приложение покажет при первом запуске.
   Ключи хранятся только на этом компьютере; сменить их можно в «Кастомизация» → «Приложение».
   Если Telegram отклонит ключи, приложение само вернётся к этому экрану.

Можно и вшить ключи в сборку через `.env` (`TELEGRAM_API_ID`, `TELEGRAM_API_HASH`) — тогда экран не появляется.
Сборка без ключей в `.env` подходит для раздачи: каждый пользователь вводит свои.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` + `npm run electron:dev` | Веб-сервер разработки на `localhost:1234` и окно Electron поверх него (горячая перезагрузка) |
| `npm run dev:mocked` | Фейковый клиент без входа в аккаунт на `localhost:1235` — удобно для работы над визуалом |
| `npm run electron:start` | Electron с уже собранным `dist/` (через протокол `app://abudjagram`) |
| `npm run electron:pack` | Продакшен-сборка и распакованное приложение в `release/win-unpacked` |
| `npm run electron:build` | Продакшен-сборка и установщик NSIS в `release/` |

Чтобы открыть окно Electron поверх фейкового клиента: `ABUDJAGRAM_DEV_URL=http://localhost:1235 npx electron .`

Переменная `ABUDJAGRAM_PROFILE=<имя>` запускает приложение с отдельным профилем, например для второго аккаунта параллельно с основным.

## Кастомизация

Настройки → «Кастомизация»:

- **Готовые темы** — Аврора, Закат, Океан, Неон, Терминал, Классика: применяются в один клик, свой CSS и видеофон сохраняются.
- **Стекло** — полупрозрачные панели с `backdrop-filter`: размытие, плотность, насыщенность, светлая кромка, стеклянные пузыри сообщений.
- **Фон окна** — обои Telegram, анимированная «Аврора» (4 палитры), видео (файл или прямая ссылка на `.mp4`/`.webm`), затемнение фона.
  На Windows 11 дополнительно доступны системные материалы Mica и Acrylic.
- **Анимации** — множитель длительности, характер движения (плавный, пружинистый, резкий), анимация появления сообщений.
- **Сообщения и шрифт** — скругление пузырей, хвостики, шрифт (Roboto, Segoe UI, Inter, Manrope, Nunito, JetBrains Mono или любой системный), масштаб интерфейса.
- **Свой CSS** — подключается последним, поверх всех стилей приложения.
- **Приложение** — автозапуск вместе с Windows (стартует свёрнутым в трей).

Оболочка: собственный заголовок окна с системными кнопками Windows, сворачивание в трей при закрытии,
счётчик непрочитанных на значке в панели задач, мигание окна при новых сообщениях.
- **Экспорт и импорт** настроек в JSON-файл.

## Где код форка

| Путь | Назначение |
| --- | --- |
| `electron/main.cjs`, `electron/preload.cjs` | Оболочка Electron: окно, протокол `app://`, мост `window.abudjagram` |
| `src/customization/` | Настройки и их применение, стили стекла и фонов, ключи API и экран их ввода |
| `src/components/left/settings/SettingsCustomization.tsx` | Экран настроек |

Изменения в коде оригинала минимальны (пункт меню, роутинг экрана, CSP, строки локализации), чтобы было проще подтягивать обновления из upstream.
